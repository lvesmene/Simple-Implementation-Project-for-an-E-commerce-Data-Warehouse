## 任务一：face 空格根本修复（约 30 分钟）

### 步骤 1：先在 MySQL Workbench 跑 3 条验证 SQL（你自己跑）

**① 确认"会被合并的职业"只有一对：**

```sql
SELECT TRIM(REPLACE(REPLACE(face, ' ', ''), '　', '')) AS cleaned,
       COUNT(DISTINCT face) AS variants, COUNT(*) AS users
FROM dim_user_profile
GROUP BY cleaned
HAVING variants > 1;
```

【核对点】应只返回 **1 行**：`家庭主妇/主夫`，variants=2。把这行的人数记下来（步骤 3 要用）。

**② 确认清洗后 ≥100 人的职业仍是 9 个（图13 行数不变的保证）：**

```sql
SELECT COUNT(*) AS n FROM (
    SELECT TRIM(REPLACE(REPLACE(face, ' ', ''), '　', '')) AS cleaned
    FROM dim_user_profile
    GROUP BY cleaned
    HAVING COUNT(*) >= 100
) t;
```

【核对点】应返回 **9**。若变成 10，说明 `家庭主妇/主夫` 合并后跨过了 100 人门槛，图13 会多一行——那不是错误，但我们要知道，停下来告诉我。

**③ 确认行数不漏：**

```sql
SELECT COUNT(*) AS total FROM dim_user_profile;   -- 期望 10739
```

> 为什么先验证再动手：清洗是"键列重写"，万一合并出新的 ≥100 职业，图13、PowerBI、Excel 三处的核对基准都会变。先知道影响面，再决定改不改。

### 步骤 2：改 `src/export_for_validation.py`（你改，只动一处）

找到 `SQL_RFM_WIDE` 里的第一列（约 L29）：

```sql
-- 改前
        p.face,
-- 改后
        TRIM(REPLACE(REPLACE(p.face, ' ', ''), '　', '')) AS face,
```

三个函数从里到外：`REPLACE(..., ' ', '')` 删半角空格 → `REPLACE(..., '　', '')` 删全角空格 → `TRIM` 兜底。**注意第二个 REPLACE 里是全角空格**（中文输入法下按空格打出来的那个）。
