# legacy：旧版单脚本分析（已归档，不再维护）

本目录/ output/legacy/ 保存项目改进前的产出：Pandas 单脚本 + K-Means 三群 + 10 张静态图。

## 为什么归档而不是删除
它记录了方法论升级的关键决策：
- **K-Means 三群 → RFM 八类规则分群**：聚类结果不可解释（"第0/1/2类"），
  业务无法据此行动；RFM 用 NTILE(4) 打分 + CASE WHEN 命名，
  每个分群有明确的业务含义和对应运营动作。
- **单脚本 → 五层数仓**：
单脚本是线性流程，中间结果只落在内存和 CSV 里，换个口径分析就得从 76 万行重新读、重新预处理；五层数仓把 ODS→DIM→DWD→DWS→ADS 逐层落库，一次构建、多层复用，改 ADS 口径不必回头重跑预处理。
## 口径声明
旧版的统计口径（如分群人数）与现行版本不一致，**一切以 /notes/指标口径字典.md 为准**。
